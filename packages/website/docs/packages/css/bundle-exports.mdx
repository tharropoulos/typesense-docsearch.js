title: CSS bundles and exports
description: Choose the typesense-docsearch-css v5 beta bundle for each DocSearch surface.
---

`typesense-docsearch-css` publishes compiled CSS and SCSS-named assets in `dist`. The package doesn't define an `exports` map, so import the root entry or a listed `dist` file.

## Root entry

The package fields `main`, `unpkg`, and `jsdelivr` all point to `dist/style.css`.

These imports load the same full search-and-modal bundle:

```js title="app.js"
import 'typesense-docsearch-css';
import 'typesense-docsearch-css/dist/style.css';
```

Use only one of them.

## Choose imports by surface

Each surface needs a different set of assets. See [Published assets](#published-assets) for the full file list.

### Search button only

```js title="app.js"
import 'typesense-docsearch-css/dist/button.css';
```

### Keyword-search modal

```js title="app.js"
import 'typesense-docsearch-css/dist/button.css';
import 'typesense-docsearch-css/dist/modal.css';
```

Use the root bundle instead if your modal can show Agent Studio responses.

### Agent Studio modal

```js title="app.js"
import 'typesense-docsearch-css';
```

### Sidepanel

```js title="app.js"
import 'typesense-docsearch-css';
import 'typesense-docsearch-css/dist/sidepanel.css';
```

The Sidepanel reuses Agent Studio response and Markdown classes from the root bundle, so `sidepanel.css` isn't the complete Sidepanel presentation by itself.

## Load from a CDN

```html title="index.html"
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/typesense-docsearch-css@^5/dist/style.css"
/>
```

Add the Sidepanel asset when needed:

```html title="index.html"
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/typesense-docsearch-css@^5/dist/sidepanel.css"
/>
```

Use the caret beta range so compatible beta updates remain available.

## Published assets

| Path | Contents |
| --- | --- |
| `typesense-docsearch-css/dist/style.css` | Variables, search button, modal, and Agent Studio response styles. |
| `typesense-docsearch-css/dist/_variables.css` | Shared light and dark custom properties. |
| `typesense-docsearch-css/dist/button.css` | Variables and search-button styles. |
| `typesense-docsearch-css/dist/modal.css` | Variables and keyword-search modal styles. |
| `typesense-docsearch-css/dist/_askai.css` | Agent Studio modal response and Markdown styles. |
| `typesense-docsearch-css/dist/sidepanel.css` | Variables, Sidepanel button, panel layout, and Sidepanel-specific overrides. |

Each asset also has an equivalent `.scss` file: `style.scss`, `_variables.scss`, `button.scss`, `modal.scss`, `_askai.scss`, and `sidepanel.scss`. The build writes the compiled bundle to both extensions; these aren't Sass source partials.

## React style bridge exports

`typesense-docsearch-react` v5 beta also exposes JavaScript style bridge entry points. They re-export files from `typesense-docsearch-css`:

| Import path                        | CSS target                           |
| ---------------------------------- | ------------------------------------ |
| `typesense-docsearch-react/style`           | `typesense-docsearch-css`                     |
| `typesense-docsearch-react/style/variables` | `typesense-docsearch-css/dist/_variables.css` |
| `typesense-docsearch-react/style/button`    | `typesense-docsearch-css/dist/button.css`     |
| `typesense-docsearch-react/style/modal`     | `typesense-docsearch-css/dist/modal.css`      |
| `typesense-docsearch-react/style/askai`     | `typesense-docsearch-css/dist/_askai.css`     |
| `typesense-docsearch-react/style/sidepanel` | `typesense-docsearch-css/dist/sidepanel.css`  |

Prefer direct `typesense-docsearch-css` imports when your bundler supports CSS package imports. They show which assets enter your bundle and work across the DocSearch React packages.
