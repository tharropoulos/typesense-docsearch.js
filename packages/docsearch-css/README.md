# typesense-docsearch-css

Style package for [DocSearch](http://docsearch.algolia.com/), the best search experience for docs.

## Installation

```bash
npm install typesense-docsearch-css@5
```

If you don’t want to use a package manager, you can use a standalone endpoint:

```html
<script src="https://cdn.jsdelivr.net/npm/typesense-docsearch-css@5"></script>
```

## Get started

```js
import 'typesense-docsearch-css';
```
